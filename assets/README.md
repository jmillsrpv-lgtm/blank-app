# Sound effects

Put a short `cha-ching.mp3` in this folder (half a second to a second long)
and it will be mixed in on every punchline scene.

Free ones: https://freesound.org  — search "cash register", download as MP3,
rename it to exactly `cha-ching.mp3`, and drop it here.

Without the file the episode is still made, just without the cha-ching.
